# Data Retention Policy
Effective: {{effective}} · Version 1.0

We keep data only as long as it is needed.

## On the phone
Customer lists and records stay until you delete them or uninstall the app.

## On our server
- **Call records:** deleted automatically {{retentionDays}} days after the call.
- **User records** (name, code, device link, consent record): kept while the user has access. Deleted when the user, the Team Leader or the Admin removes them, or when the user deletes everything.
- **Team Leader records:** kept while the subscription exists. A cancelled or expired team is kept until the Admin deletes it, so that it can be renewed.
- **Deleted team:** all its users and call records are deleted at once.
- **Temporary technical data** (rate-limit counters): kept in memory for minutes and never saved.
- **Backups, if made:** kept for at most 30 days.

## Changes
If we change these periods we will update this page and tell you in the app.
